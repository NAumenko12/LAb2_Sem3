# Лабораторная работа 2. Алгоритмы и абстрактные структуры данных

Номер в списке – 16. Все задания собраны в одну программу на C++ (C++11),
аналогичная версия написана на Go.

## Сборка

```sh
make          # C++, программа build/lab2
make go       # Go, программа build/go/lab2
make clean    # удалить собранные файлы
```

## Запуск

```sh
./build/lab2 --query 'КОМАНДА данные'
./build/lab2 --file set.json --query 'SETADD кот'
./build/lab2 --query 'HUFFMAN aaaa' --bits 0000
./build/lab2 --help
```

- `--query` – команда и входные данные
- `--file` – путь к файлу множества (только для задания 2)
- `--bits` – битовая строка для расшифровки (только для задания 5)

При неверных данных выводится сообщение `Ошибка: ...`, программа завершается с кодом 1.

## 1. Обход в глубину

Обход выполняется с помощью стека, без рекурсии.

**Дерево.** Из чисел строится бинарное дерево поиска, повторы не добавляются,
ноль завершает ввод. Выводится прямой обход.

```sh
./build/lab2 --query 'DFS TREE 7 3 9 1 5'
# Обход в глубину  7 3 1 5 9
```

**Граф.** Формат: число вершин N, число рёбер M, M пар вершин, начальная вершина.
Граф неориентированный, вершины нумеруются от 1 до N.

```sh
./build/lab2 --query 'DFS GRAPH 5 5 1 2 1 3 2 4 3 4 4 5 1'
# Обход в глубину: 1 3 4 5 2
```

## 2. АТД Множество

Множество построено на хеш-таблице с цепочками: добавление, удаление и проверка
выполняются в среднем за O(1). Данные хранятся в файле как JSON-массив строк,
поддерживается UTF-8.

```sh
./build/lab2 --file set.json --query 'SETADD кот'    # -> кот
./build/lab2 --file set.json --query 'SETADD пёс'    # -> пёс
./build/lab2 --file set.json --query 'SET_AT кот'    # -> TRUE
./build/lab2 --file set.json --query 'SETPRINT'      # {кот, пёс}
./build/lab2 --file set.json --query 'SETDEL кот'    # -> кот удалён
cat set.json                                         # ["пёс"]
```

## 3. Максимальное пересечение

Ищутся две пары множеств с наибольшим числом общих элементов. Если максимум
достигается на нескольких парах, выводятся все.

```sh
./build/lab2 --query 'INTER {{1,2,3},{2,3,4},{5,6},{3,4,5}}'
# {{1, 2, 3}, {2, 3, 4}}, количество общих элементов: 2 (2, 3)
# {{2, 3, 4}, {3, 4, 5}}, количество общих элементов: 2 (3, 4)
```

## 4. Пирамида

Формат: N, затем N пар «ширина высота». Блоки одной ширины не ставятся друг
на друга, поэтому ответ – сумма максимальных высот по всем различным ширинам.
Блоки сортируются, сложность O(N log N).

```sh
./build/lab2 --query 'PYRAMID 3 3 1 2 2 3 3'
# Максимальная высота: 5
```

## 5. Алгоритм Хаффмана

Выводятся частоты и коды символов, закодированная строка и её расшифровка.
С ключом `--bits` расшифровывается произвольная битовая строка по тому же дереву.

```sh
./build/lab2 --query 'HUFFMAN abracadabra'
# a — 5 — 0
# r — 2 — 10
# b — 2 — 110
# c — 1 — 1110
# d — 1 — 1111
# Код: 01101001110011110110100
# Расшифровка: abracadabra
```

## 6. Хеш-таблицы

**6.1.** Метод цепочек: массив односвязных списков, при заполнении на 75% таблица
увеличивается вдвое. Кукушка: два массива по 11 ячеек и две хеш-функции, при
цикле вытеснений (больше 20 шагов) вставка отменяется, старые ключи сохраняются.
Команда `CUCKOO` показывает, как ключи разместились в обеих таблицах.

```sh
./build/lab2 --query 'CUCKOO a l w'
./build/lab2 --query 'CUCKOO ax cq fa'   # Кукушка: цикл при добавлении ключа fa
```

Среднее время прогона (вставка, успешный и неуспешный поиск, удаление),
clang++ -O2, 30 000 повторов:

| Ключей | Цепочки, мкс | Кукушка, мкс |
|---:|---:|---:|
| 5 | 0.789 | 0.454 |
| 11 | 0.912 | 0.584 |
| 22 | 1.401 | 1.247 |

Подробнее: [zadachi/zadanie6/zad_hesh_tab_analiz.md](zadachi/zadanie6/zad_hesh_tab_analiz.md).

**6.2.** Самая длинная подстрока без повторов ищется скользящим окном,
хеш-таблица хранит последнюю позицию каждого символа. Один проход по строке.

```sh
./build/lab2 --query 'SUBSTRING abcabcbb'
# Цепочки: 3 (abc)
```

## 7. LFU-кэш

Формат: ёмкость, число запросов, затем команды `SET ключ значение` и `GET ключ`.
Хеш-таблица хранит значение и частоту обращений, для каждой частоты есть
двусвязный список ключей. Вытесняется ключ с наименьшей частотой, при равной
частоте – самый давний.

```sh
./build/lab2 --query 'LFU 2 7 SET 1 10 SET 2 20 GET 1 GET 1 GET 2 SET 3 30 GET 2'
# Результат: 10 10 20 -1
```
